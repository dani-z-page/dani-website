How to install

  • Gmail: click Copy signature above → Gmail ⚙ Settings → See all settings → General → Signature → Create new → paste into the box → Save changes.
  • Apple Mail: Mail → Settings → Signatures, create one, then paste. If it pastes as plain text, uncheck “Always match my default message font,” then paste again.
  • Outlook: File → Options → Mail → Signatures (or, on the web, Settings → Mail → Compose and reply), create a signature and paste.

If pasting the rich version doesn’t stick, copy the raw HTML below instead and use your mail client’s “edit signature HTML / source” option.
